# Competency tracker

**Levels**
- **0**: not started.
- **1**: seen it; I recognise it when I read it.
- **2**: can do it with notes, hints or examples.
- **3**: did it **independently**: no hints, no AI, and the tests pass.
- **4**: **mastered**. I did it independently on a *new* problem, can explain it, and rebuilt it from a blank page. I (Claude) confirm level 4 in a review.

**Rule:** a level only counts with **evidence**: a link to a file, test, PR, or written explanation. Passing an exam is not evidence.
